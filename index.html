How to download

Two files, two clicks. Keep the resource pack as a .zip. Do not unzip it.

  1. Download the plugin

    Press Download plugin. You get a file called IllegalItems.jar.

  2. Download the resource pack (required)

    Press Download resource pack. This file is a must. You get IllegalItems-ResourcePack.zip. Leave it zipped.

  3. Check the files (optional)

    Your browser may warn that .jar files can be harmful. That is normal for any plugin. To confirm the file is unchanged, compare its SHA1 with the one on this page. On Windows, run certutil -hashfile IllegalItems.jar SHA1 in Command Prompt.

How to set it up on your server

Do the plugin first, then the resource pack. Both take about five minutes.

Install the plugin

  1. Stop the server

    Use the stop command in the console or your hosting panel.

  2. Add the jar

    Put IllegalItems.jar in your server's plugins folder.

  3. Start the server

    Look for this line in the console:

    IllegalItems enabled.

    A new folder plugins/IllegalItems with a config.yml appears.

Turn on the resource pack

  1. Open server.properties

    Find it in your main server folder.

  2. Paste these three lines

    Replace any existing lines with the same names.

    resource-pack=https://YOUR-SITE/downloads/IllegalItems-ResourcePack.zip
resource-pack-sha1=59940e9743780e09ee3ae00883d91017ada7e1e5
require-resource-pack=true

    Once this site is online, the link above fills in with its real address.

  3. Restart the server

    Players get a download prompt when they join. They must accept it to stay on the server.

require-resource-pack=true makes the download mandatory. Players see a prompt when they join. If they decline, the server removes them, so everyone plays with the textures.

How to use

Give yourself the items, hold the sword, and use its powers.

Give items

Run this in game or in the console. It needs the illegalitems.give permission, which operators have by default.

/illegal give <player> <sword|helmet|chestplate|leggings|boots|armor|all>

Example: /illegal give Steve all gives Steve the sword and all four armour pieces. You can also type /illegalitems.

Sword controls

  • Right-click with the sword in your main hand to use the selected power.
  • Sneak and right-click to switch to the next power. The name appears above your hotbar.
  • By default every hit with the sword does 1000 damage, so most targets die in one hit.

Change the settings

Edit plugins/IllegalItems/config.yml, then restart the server.

# Seconds between uses of each power
cooldowns:
  LIGHTNING: 5
  FIREBALL: 3
  DASH: 4
  BLINK: 6
  BLAST: 8
  FREEZE: 15
  HEAL: 30

lightning-range: 40
blast-damage: 12.0
blast-radius: 8.0
freeze-radius: 10.0
blink-distance: 15

# Damage per sword hit. 1000 kills in one hit. 0 = normal damage.
sword-damage: 1000.0

name-animation:
  enabled: true
  interval-ticks: 2

If you update the plugin and the new options are missing, delete config.yml and restart. A fresh one is created.

Help

Common problems and what to do.

The items look like normal netherite
The resource pack is not loaded. Check that the link and SHA1 in server.properties are correct, restart the server, and accept the pack when you join. If you changed the zip, the SHA1 changes too. Get the new one from the download section.
The plugin does not start
It needs Paper 1.20.4 and Java 17 or newer. It does not work on Spigot or Bukkit. Read the first error in the console and check that the jar is directly inside the plugins folder.
The name only glitches sometimes
The name glitches while the item is in your inventory or hotbar. The item in your hand and the armour you wear keep a fixed name. If it changed every moment, Minecraft would replay the equip animation and sound.
I cannot see the black name well
The name is black with dark gray, so it is dark on Minecraft's dark tooltip. This is intended. Flashes of red and white help it stand out.
My face is hidden by the helmet
This site's pack has an open visor so your face shows. If it is still covered, the pack in use is an older version. Download the latest zip and replace it on your server.
Can I give the sword to everyone?
The sword kills in one hit, so it is best kept for admins. Only players with illegalitems.give (operators by default) can spawn items. You can lower sword-damage in the config.
Every enchanted item looks less shiny
The pack dims the purple enchantment glow so the black and red textures stay visible. To keep the normal glow, delete the assets/minecraft/textures/misc folder inside the zip.
All my netherite armour changed look
The armour worn on the body replaces the normal netherite armour texture for players using this pack. To avoid that, delete the textures/models/armor and textures/entity/equipment folders inside the zip. The items keep their custom inventory icons.
